# 📌 Project Overview:
The project involves building a Cisco-based organizational network that connects departmental computers, network printers, servers, and other network resources through a Cisco switch and router. 

The infrastructure will also provide essential network services, including
1.DHCP for automatic IP address allocation, 
2.DNS for hostname and domain-name resolution, 
3.Mail Server using SMTP and POP3 for organizational email communication.

The project covers four main areas:

1.Cisco Switch Configuration: Configure important switch settings to provide a secure and functional network environment.
2.Network Design: Develop a topology containing a Cisco router, Cisco switch, five departmental networks, servers, computers, and network printers.
3.Server Deployment: Configure DHCP pools, DNS records, domain services, and staff email accounts.
4.Testing and Verification: Confirm DHCP addressing, inter-department connectivity where permitted, printer accessibility, DNS resolution, and successful email communication.

# 🎯 Objectives:
The main objectives of this project are to:

To design and implement a secure, functional, and centralized enterprise network that connects five organizational departments using VLANs and inter-VLAN routing, while providing essential network services such as DHCP, DNS, email, and network printing.
By completing the project, you should be able to:

1.Configure Cisco network devices including a switch and router for a functional and secure network.

2.Configure DHCP services to automatically provide client devices with IP addresses, default gateways, and DNS settings.

3.Configure DNS services by creating an organizational domain and DNS records so users can access network resources using names instead of IP addresses.

4.Deploy an email server using SMTP and POP3 and create staff email accounts for sending and receiving email.

5.Provide network printer connectivity so printers are reachable across the appropriate network segments.

6.Test and troubleshoot network connectivity, including DHCP address assignment, inter-department communication, DNS resolution, printer connectivity, and email services.

7.Apply network security best practices when configuring the organization's switch, router, VLANs, and other network components.

8.Document the complete network implementation professionally, including the topology, configurations, test results, and screenshots.

# Purpose of the Lab
The project is intended to help you learn how to:

1.Design a centralized organizational network connecting HR, Finance, Sales and Marketing, Operations, and IT departments.
2.Configure Cisco switches and routers to provide reliable connectivity.
3.Use VLANs to logically separate departments and improve network organization and security.
4.Implement inter-VLAN routing so different departments can communicate when permitted.
5.Deploy DHCP, DNS, and Mail services for automatic IP addressing, hostname resolution, and email communication.
6.Connect and provide access to shared resources, particularly network printers.
7.Apply basic network security practices when configuring Cisco devices and network services.
8.Test and troubleshoot the network to confirm that DHCP, DNS, email, printers, and communication between departments work correctly.
9.Document the network professionally, including configurations, topology, screenshots, and test results.
